# Claude Animated Shorts

A Claude Code skill and starter templates for producing original vertical animated story shorts with Remotion and Three.js.

## Included
- `SKILL.md`: the animation production skill.
- `CLAUDE.md`: project workflow and production rules.
- `HANDOFF_PROMPT.md`: a prompt for starting a new Claude Code task.
- `templates/`: example bridge-scene, audio, and validation code.

## Important
This is a skill and template package, not a complete standalone Remotion application. The bridge scene and its soundtrack are story-specific examples; do not reuse their timings or audio schedule for unrelated stories. Build a new timeline and sound schedule to match each approved narration.

Install the skill in your Claude Code skills directory, then copy `CLAUDE.md` into the root of the Remotion project you want to work on. Review the source and dependencies before running any scripts.
